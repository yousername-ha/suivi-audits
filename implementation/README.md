# Implémentation

Le [socle ASTRA](socle-astra/README.md) rassemble les règles communes, l’inventaire des menus, la recette et le prompt pour un agent d’implémentation.

Les consignes et le suivi propres à chaque fonctionnalité se trouvent dans [le catalogue](../fonctionnalites/README.md), colonne « Implémentation ». Une maquette n’est pas automatiquement une intégration réalisée.
