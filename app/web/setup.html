Récupérer le jeton

Sur le serveur, dans le dossier de l'application, exécuter l'une des commandes suivantes. Le jeton affiché est valable 24 h ; en générer un nouveau annule le précédent.

docker compose exec app setup-token

ou, pour retrouver le jeton émis au démarrage :

docker compose logs app | grep -A3 JETON

La double authentification sera configurée à l'étape suivante.
