## Constats bloquants

### RSSI-05 — Les parties intéressées saisies à l'écran ne sont comptées nulle part (BUG-020)

- Gravité : bloquant (donnée fausse dans une entrée de revue de direction)
- Étapes : 1 et 11 — Référence : ISO/IEC 27001:2022, 4.2 et 9.3.2
- Observé : fiche « Adhérents du groupement (fictif) » créée par « Ajouter partie intéressée » (exigences traitées : Oui,
  dernière revue : 01/06/2025), visible dans le tableau (« 1 fiches »). Le bandeau affiche « 0 parties intéressées, 0
  exigences traitées, 0 partiellement ou non traitées, 0 non revues depuis un an ». La revue de direction reprend « 0 partie
  intéressée enregistrée(s), 0 non revue(s) depuis un an ».
- Cause confirmée (lecture du code) : `apps/web/src/pilotage/Pestel.tsx` (`SynthesePartiesBandeau`) et
  `apps/api/src/pilotage/revue.ts` lisent `interested` de `/api/suivi/etat` (registre historique), pas les objets
  `stakeholder`.
- Attendu : compteurs et entrée de revue calculés sur les fiches de la rubrique.
- Reproductible par : `30-recette-2026-11-12.spec.ts` « RSSI-05 ouvert ».

### RSSI-19 — Une revue de direction validée n'est pas reconnue comme dernière revue (BUG-021)

## Remarques à arbitrer

- Rôles : pas de rôle d'auditeur interne (un « Lecteur » ne peut pas saisir de constat, un « Contributeur » peut modifier la
  DdA qu'il audite) ; la fiche d'audit n'a pas de champ auditeur (9.2.2, impartialité).
- Les écrans « Choisir un nouveau mot de passe » portent aussi « Toggle password visibility » (BUG-018) ; l'écran de
  connexion est correct (« Afficher la saisie »).
- Sélecteurs de mesures et de justificatifs : titres seuls, sans code (« 8.13 » ne trouve rien), homonymes indistincts
  (« Généralités » trois fois, cinq « Test mensuel de restauration (fictif) »), tous types d'objets mélangés.
- Vocabulaire technique visible sur une installation neuve : « socle historique », « source v2 », « Référence liée :
  legacy:items:ISO-4.1 », statut de version « non_analysé », « Dates et heures en UTC ».
- Valeurs par défaut favorables : stratégie « Réduire » avant toute appréciation, « Efficace » dans la vérification
  d'efficacité, « Organisation certifiée ISO 27001 » cochée à l'installation.
- Séries de tâches proposées : toutes tirées de l'ISO 9001 (dont l'étalonnage 7.1.5.2) ; aucune pour l'ISO 27001 ou HDS.
- Pourcentages sur ensemble vide (« 0 % SaaS avec MFA (0/0) ») ; « 1 fiches ».
- Incident de catégorie « rançongiciel » créé avec la qualification par défaut « Incident » : non compté comme incident de
  sécurité, sans alerte.
- HDS : « Qualifier les activités » renvoie à la DdA HDS ; pas d'écran pour qualifier les six activités d'hébergement.
- Accessibilité : boutons de fermeture sans nom sur plusieurs fenêtres ; en-têtes de tableau sans rôle d'en-tête ; le lien
  « Organisation » du menu déplie un sous-menu au lieu de naviguer ; registre « Mesures » vide à côté des 93 mesures de la DdA.
- Le périmètre racine s'appelle « Pilotage de l'organisation » après l'installation, pas du nom saisi pour l'organisation.
