# Pilotage multi-référentiels

Le module a été réorganisé sous le nom **Pilotage**. Il accompagne les démarches qualité (SMQ), sécurité (SMSI), HDS et intégrées, sans création de SMSI dans le parcours normal. Les données et accès existants sont conservés.

Consultez le [guide Pilotage](PILOTAGE.md) et la [livraison G/H/K et début E](LOT-G-H-K-DEBUT-E.md). L’ancienne adresse `/grc` redirige vers `/pilotage`.
