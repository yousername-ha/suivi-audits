# Captures natives — fiches sobres (22/11/2026)

Pile Docker réelle (images construites depuis la branche, base neuve, données fictives créées par la suite de bout en
bout), navigateur Chromium du conteneur Playwright, rapport de pixels de 1, aucune retouche. Thème et densité posés par
les attributs de la page, comme le fait l'application. Mesures relevées au moment de chaque capture :
[bilan.txt](bilan.txt) (fenêtre dans l'écran, défilement vertical, défauts, erreurs).

Ces captures sont fournies pour la validation graphique du RSSI ; elles ne la remplacent pas.
