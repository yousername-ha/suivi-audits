Le code fourni est un exemple figé de réalisation et ses chemins peuvent avoir changé. Ne crée pas de nouveau backend, de table, d’API, de faux résultat ou de service Assistant pour rendre une image ressemblante. Une autorisation graphique ne modifie pas une méthode de risque, un calcul d’indicateur, un taux de couverture ou le résultat d’une validation.
