Le retard dépend de l’échéance et de l’état de l’action ; il ne remplace pas son état. Une occurrence validée n’est plus en retard, y compris avec un résultat KO. Le résultat OK / KO / NA est affiché séparément. Les fenêtres, exclusions, rappels et enchaînements restent accessibles dans la fiche de la série. Les compteurs de cette proposition utilisent uniquement le jeu fictif présenté, sans taux de conformité ni historique inventé.
